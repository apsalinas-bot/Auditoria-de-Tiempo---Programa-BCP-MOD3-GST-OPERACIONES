Bloque 3 · Concepto (15 min)

Ishikawa — Las 6M explicadas

Síntoma del ejemplo: "Mis pedidos especiales siempre salen tarde"

Para cada M, la pregunta es: ¿podría venir de aquí? Toca cada categoría para ver la definición y el ejemplo.

👷 Mano de Obra — ¿El problema viene de quién hace el trabajo? +

Capacitación, dependencia de una sola persona, rotación, habilidades no transferidas.

Ejemplo: el armado final del pedido solo lo sabe hacer la dueña. Si ella no está, el pedido se atrasa.

📋 Método — ¿El problema viene de cómo se hace? +

El procedimiento, la secuencia de pasos, si está documentado o solo existe en la cabeza.

Ejemplo: no hay un orden fijo para los pedidos especiales — cada vez se hace diferente y se pierde tiempo.

📦 Materiales — ¿El problema viene de los insumos? +

Calidad, disponibilidad, tiempo de entrega, dependencia de un solo proveedor, stock insuficiente.

Ejemplo: la crema especial se compra en un solo local. Cuando no hay, el pedido se paraliza.

⚙️ Máquina — ¿El problema viene del equipo o herramienta? +

Horno, máquina de coser, celular, impresora — cualquier herramienta clave. Capacidad, mantenimiento, recursos compartidos.

Ejemplo: el único horno compite entre el pan del día y los pedidos especiales. El especial siempre pierde.

🏠 Medio — ¿El problema viene del entorno? +

Espacio físico, temperatura, luz, ubicación, temporada, también entorno digital (conexión, plataformas).

Ejemplo: la cocina es chica y en diciembre el calor derrite la crema más rápido — el proceso se alarga.

📏 Medición — ¿El problema viene de no medir lo correcto? +

No saber cuánto tarda cada paso, no controlar inventario, confirmar pedidos "de cabeza" sin revisar capacidad real.

Ejemplo: la dueña acepta un pedido para el sábado sin calcular si tiene tiempo. El atraso se descubre cuando ya es tarde.
